# PRD: 자기경영 관리 서비스 
## 1. 개요

### 1.1 배경 및 문제의식
기존 생산성/할일관리 앱은 대부분 "얼마나 해냈는가"를 중심에 둔다. 완료율, 스트릭, 목표 달성처럼 성과를 재촉하는 지표는 컨디션이 좋지 않은 날 오히려 부담과 자책을 유발한다.

이 서비스는 성과가 아니라 **상태**를 중심에 둔다. 오늘의 내 상태를 살피고, 감정을 언어화하고, 그에 맞게 일정과 할 일을 가볍게 조정하도록 돕는 것이 목표다.

### 1.2 제품 원칙
- **상태 우선**: "무엇을 해냈나"보다 "지금 어떤 상태인가"를 먼저 묻는다.
- **가벼움**: 입력은 짧고 즉각적이어야 한다(선택형 위주, 긴 서술 강요 금지).
- **비재촉**: 진행률 %, 스트릭, 랭킹 등 압박형 UI를 지양한다.
- **자기 이해 축적**: 하루하루의 기록이 나를 이해하는 데이터로 쌓인다.

### 1.3 타깃 사용자
번아웃, 무기력, 감정 기복을 스스로 관리하고 싶은 1인 사용자. 팀/협업 기능은 대상 밖.

---

## 2. 정보 구조 (5개 핵심 영역)

| 영역 | 역할 |
|---|---|
| ① 오늘 관리 | 하루의 진입점. 지금 상태를 확인하고 오늘 할 일을 가볍게 배치 |
| ② 감정 관리 | 감정을 선택·기록하고 그 이면의 욕구를 확인 |
| ③ 일정 관리 | 정해진 시간의 일정(캘린더형) |
| ④ 태스크 관리 | 시간이 고정되지 않은 할 일(리스트형) |
| ⑤ 기록 관리 | 하루/주 단위로 쌓인 데이터를 돌아봄 |

오늘 관리가 홈 화면이며 나머지 4개 영역의 요약이 모이는 허브 역할을 한다.

---

## 3. MVP (1차 개발 범위)

> 원칙: 입력 마찰을 최소화하는 선택형 UI를 우선 구현하고, 통계/분석/자동화는 전부 2차로 미룬다.

### 3.1 오늘 관리
- **현재 상태 체크인**: 하루 1회(또는 원할 때마다) 컨디션/에너지 수준을 간단히 선택 (예: 5단계 아이콘 선택)
- **오늘 할 일**: 태스크 관리에서 오늘 날짜로 지정된 항목 + 오늘 일정 요약을 한 화면에 노출
- **나를 위한 일**: 생산성 업무와 구분되는 셀프케어 항목 1개를 별도 섹션에 노출 (직접 입력 또는 사전 정의 목록에서 선택)

MVP 범위: 상태 선택 UI, 오늘 항목 통합 뷰. 상태 변화 추이 그래프 등은 제외.

### 3.2 감정 관리
- **감정 선택**: 사전 정의된 감정 태그(예: 기쁨/불안/짜증/무기력 등) 중 선택하는 단순 선택형 UI
- **상황 기록**: 감정을 유발한 상황을 짧은 텍스트로 자유 입력 (선택 항목, 강제하지 않음)
- **욕구 확인**: 감정에 연결된 욕구를 선택지에서 고르게 함 (예: 쉬고 싶다/인정받고 싶다/혼자 있고 싶다 등 고정 리스트)

MVP 범위: 감정-상황-욕구 3단 기록 폼과 저장. 감정 패턴 분석, 태그 커스터마이징은 제외.

### 3.3 일정 관리
- **일/주/월 보기**: 캘린더 기본 3가지 뷰 전환
- **일정 등록/수정**: 제목, 날짜, 시간(시작/종료), 간단 메모만 지원

MVP 범위: 단일 사용자용 CRUD 캘린더. 반복 일정, 알림, 외부 캘린더 연동은 제외.

### 3.4 태스크 관리
- **할 일 등록**: 제목 + 날짜(선택)
- **우선순위**: 상/중/하 등 단순 3단계
- **상태 전환**: 완료 / 보류 / (다른 날짜로) 이동

MVP 범위: 리스트형 CRUD + 상태 전환. 서브태스크, 태그, 반복 태스크는 제외.

### 3.5 기록 관리
- **하루 기록**: 오늘 관리 + 감정 관리에서 입력된 데이터를 하루 단위로 자동 취합해 보여주는 뷰 (별도 입력 없음)
- **이전 기록 조회**: 날짜별로 과거 기록을 다시 열람 (읽기 전용)

MVP 범위: 자동 취합 뷰 + 날짜 탐색. **주간 돌아보기는 2차로 이연** (아래 참고).

## 4. 2차 이후 (Post-MVP)

성과나 편의를 더하는 기능. MVP 검증 후 우선순위 재산정.

- **주간 돌아보기**: 한 주간의 상태·감정·완료 태스크를 요약해 회고 질문(예: 이번 주 나를 힘들게 한 것은?)과 함께 제시
- 감정/상태 추이 시각화 (주/월 그래프, 캘린더 히트맵)
- 감정 태그·욕구 리스트 커스터마이징
- 일정 반복 등록, 알림/리마인더
- 외부 캘린더 연동 (Google Calendar 등)
- 태스크 서브태스크, 라벨/태그, 반복 태스크
- 하루 기록에 대한 자유 일기(저널링) 입력
- 상태 기반 할 일 추천 (예: 에너지가 낮은 날엔 가벼운 태스크만 제안)
- 데이터 내보내기/백업
- 알림 톤 커스터마이징 (재촉형 문구 배제 원칙 유지한 채)

## 5. 비목표 (Out of Scope)
- 팀/협업, 공유, 소셜 기능
- 성과 랭킹, 스트릭, 뱃지 등 게이미피케이션
- 타인과의 비교 지표

---

## 6. 성공 기준 (MVP 단계)
정량적 "완료율" 대신, 서비스 원칙에 맞는 지표로 판단한다.
- 사용자가 하루 최소 1회 상태 체크인을 부담 없이 지속하는가 (재방문율)
- 감정 기록 입력까지 걸리는 시간이 짧은가 (입력 마찰 측정)
- 기록 관리에서 과거 기록을 다시 찾아보는 행동이 발생하는가 (자기 이해 목적 달성 여부의 대리 지표)
