# Sitemap & 기능정의서: 자기경영 관리 서비스

> 기준 문서: [PRD.md](./PRD.md)
> 범위 표기: **[MVP]** 1차 개발 / **[P2]** 2차 이후(Post-MVP)
> 하단 GNB(전역 내비게이션) 탭 5개(오늘/감정/일정/태스크/기록) 구조를 기본 골격으로 한다.

---

## 1. 사이트맵 (구조도)

```
자기경영 관리 서비스
│
├── 01. 오늘 (홈)                          /today                      [MVP]
│
├── 02. 감정 관리                          /emotions                   [MVP]
│    └── 감정 기록 작성                    /emotions/new                [MVP]
│
├── 03. 일정 관리                          /calendar                   [MVP]
│    ├── (일/주/월 뷰 전환은 동일 경로 내 쿼리/상태로 처리)
│    ├── 일정 등록                         /calendar/new                [MVP]
│    └── 일정 수정                         /calendar/:eventId/edit      [MVP]
│
├── 04. 태스크 관리                        /tasks                      [MVP]
│    ├── 태스크 등록                       /tasks/new                   [MVP]
│    └── 태스크 수정                       /tasks/:taskId/edit          [MVP]
│
├── 05. 기록 관리                          /records                    [MVP]
│    ├── 하루 기록 상세                    /records/:date               [MVP]
│    └── 주간 돌아보기                     /records/weekly              [P2]
│
└── 06. 설정 (공통/부가)                   /settings                   [MVP-lite]
     ├── 사전 정의 목록 관리(감정/욕구/셀프케어) /settings/presets       [P2]
     └── 데이터 내보내기/백업                /settings/data              [P2]
```

- GNB(하단 탭 등)에는 01~05 다섯 개 영역만 노출한다. 06 설정은 PRD 범위 밖의 공통 인프라 페이지로, 별도 아이콘(우상단 등)으로 최소 노출한다.
- `/calendar/new`, `/calendar/:eventId/edit`, `/tasks/new`, `/tasks/:taskId/edit`는 별도 풀페이지가 아니라 모달/바텀시트로 구현 가능. 라우팅 관점의 "페이지"로만 구분해 정의한다.

## 3. 페이지별 기능정의서

### P-01. 오늘 (홈)
**경로**: `/today` · **역할**: 앱 진입 시 첫 화면. 하루의 상태를 점검하고 오늘 할 일을 한눈에 보는 허브.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-01-1 | 현재 상태 체크인 | 컨디션/에너지 수준을 5단계 아이콘 등으로 선택. 하루 중 언제든 재선택 가능 | MVP |
| F-01-2 | 오늘 일정 요약 | `/calendar`에서 오늘 날짜에 해당하는 일정을 시간순 리스트로 노출 | MVP |
| F-01-3 | 오늘 태스크 요약 | `/tasks`에서 오늘 날짜로 지정된 항목을 우선순위순으로 노출, 완료 체크 가능 | MVP |
| F-01-4 | 나를 위한 일 | 셀프케어 항목 1개를 별도 섹션에 노출. 사전 정의 목록에서 선택 또는 직접 입력 | MVP |
| F-01-5 | 감정 기록 바로가기 | "지금 기분 기록하기" CTA → P-03 이동 | MVP |
| F-01-6 | 상태 변화 추이 | 최근 상태 체크인 히스토리를 그래프로 표시 | P2 |
| F-01-7 | 상태 기반 태스크 추천 | 낮은 에너지 상태일 때 가벼운 태스크만 우선 노출 | P2 |

**이동 경로**: 일정 요약 항목 클릭 → P-04 / 태스크 요약 항목 클릭 → P-07 / 감정 CTA → P-03

---

### P-02. 감정 관리 홈
**경로**: `/emotions` · **역할**: 오늘 기록한 감정들을 시간순으로 보고 새 기록을 시작하는 진입 화면.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-02-1 | 오늘 감정 기록 리스트 | 오늘 작성된 감정-상황-욕구 기록을 시간순 카드로 표시 | MVP |
| F-02-2 | 새 감정 기록 시작 | "감정 기록하기" 버튼 → P-03 이동 | MVP |
| F-02-3 | 감정 추이 시각화 | 주/월 단위 감정 분포·빈도 그래프 | P2 |

**이동 경로**: 새 감정 기록 → P-03 / 과거 감정 기록은 P-10, P-11에서 날짜별로 조회

---

### P-03. 감정 기록 작성
**경로**: `/emotions/new` · **역할**: 감정을 선택하고 상황·욕구를 짧게 기록하는 3단 입력 폼.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-03-1 | 감정 선택 | 사전 정의된 감정 태그(기쁨/불안/짜증/무기력 등) 중 1개 이상 선택하는 그리드형 선택 UI | MVP |
| F-03-2 | 상황 기록 | 감정을 유발한 상황을 짧은 텍스트로 입력 (선택 항목, 미입력 저장 가능) | MVP |
| F-03-3 | 욕구 확인 | 감정에 연결된 욕구를 고정 리스트에서 선택 (예: 쉬고 싶다/인정받고 싶다/혼자 있고 싶다) | MVP |
| F-03-4 | 기록 저장 | 3단 입력을 하나의 감정 기록으로 저장 후 P-02로 복귀 | MVP |
| F-03-5 | 감정 태그 커스터마이징 | 사용자가 감정/욕구 리스트 항목을 추가·수정 | P2 |

**이동 경로**: 저장 완료 → P-02 / 취소 → 이전 화면

---

### P-04. 일정 관리 (일/주/월)
**경로**: `/calendar` · **역할**: 시간이 고정된 일정을 캘린더 형태로 관리.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-04-1 | 뷰 전환 | 일/주/월 3가지 캘린더 뷰를 탭으로 전환 | MVP |
| F-04-2 | 일정 목록 표시 | 선택된 기간의 일정을 시간 순서대로 표시 | MVP |
| F-04-3 | 날짜 이동 | 이전/다음 기간 이동, 오늘로 돌아가기 | MVP |
| F-04-4 | 일정 등록 진입 | "+" 버튼 또는 빈 시간대 클릭 → P-05 이동 | MVP |
| F-04-5 | 일정 상세/수정 진입 | 기존 일정 클릭 → P-06 이동 | MVP |
| F-04-6 | 반복 일정 표시 | 반복 규칙에 따라 생성된 일정 인스턴스 렌더링 | P2 |
| F-04-7 | 외부 캘린더 연동 표시 | Google Calendar 등 연동된 일정 함께 표시 | P2 |

**이동 경로**: 신규 등록 → P-05 / 기존 일정 클릭 → P-06

---

### P-05. 일정 등록
**경로**: `/calendar/new` (모달 가능) · **역할**: 새 일정을 생성.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-05-1 | 기본 정보 입력 | 제목, 날짜, 시작/종료 시간 입력 | MVP |
| F-05-2 | 메모 입력 | 간단한 텍스트 메모 (선택 항목) | MVP |
| F-05-3 | 저장 | 입력값 검증 후 저장, P-04로 복귀하며 해당 날짜로 이동 | MVP |
| F-05-4 | 반복 설정 | 매일/매주/매월 등 반복 규칙 지정 | P2 |
| F-05-5 | 알림 설정 | 일정 전 알림 시각 지정 | P2 |

---

### P-06. 일정 수정
**경로**: `/calendar/:eventId/edit` (모달 가능) · **역할**: 기존 일정 수정 및 삭제.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-06-1 | 정보 수정 | 제목/날짜/시간/메모 수정, P-05와 동일 필드 | MVP |
| F-06-2 | 일정 삭제 | 확인 후 삭제, P-04로 복귀 | MVP |
| F-06-3 | 반복 일정 수정 범위 선택 | "이 일정만" / "이후 모든 일정" 선택 | P2 |

---

### P-07. 태스크 관리
**경로**: `/tasks` · **역할**: 시간이 고정되지 않은 할 일을 리스트로 관리.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-07-1 | 태스크 리스트 표시 | 우선순위(상/중/하) 및 상태(진행/완료/보류)별로 그룹핑해 표시 | MVP |
| F-07-2 | 상태 전환 | 리스트에서 바로 완료 처리 / 보류 처리 | MVP |
| F-07-3 | 날짜 이동 | 태스크를 다른 날짜로 이동(드래그 또는 선택) | MVP |
| F-07-4 | 태스크 등록 진입 | "+" 버튼 → P-08 이동 | MVP |
| F-07-5 | 태스크 수정 진입 | 항목 클릭 → P-09 이동 | MVP |
| F-07-6 | 서브태스크 표시 | 태스크 하위 체크리스트 | P2 |
| F-07-7 | 태그/라벨 필터 | 태그 기준 필터링 | P2 |

**이동 경로**: 신규 등록 → P-08 / 기존 항목 클릭 → P-09

### P-08. 태스크 등록

| F-08-3 | 우선순위 지정 | 상/중/하 3단계 선택 | MVP |

| F-08-5 | 반복 태스크 설정 | 매일/매주 반복 생성 | P2 |

### P-10. 기록 관리 홈 (날짜 탐색)
**경로**: `/records` · **역할**: 과거 기록을 날짜 단위로 탐색하는 진입 화면.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-10-1 | 날짜 탐색 UI | 월간 캘린더 형태로 기록이 존재하는 날짜 표시 | MVP |

### P-11. 하루 기록 상세
**경로**: `/records/:date` · **역할**: 특정 날짜의 상태·감정·태스크·일정 데이터를 자동 취합해 읽기 전용으로 표시.

| 기능 ID | 기능명 | 설명 | 구분 |
|---|---|---|---|
| F-11-1 | 상태 체크인 이력 표시 | 해당 날짜에 기록된 상태 체크인 값 | MVP |
| F-11-2 | 감정 기록 표시 | 해당 날짜의 감정-상황-욕구 기록 목록 | MVP |
| F-11-3 | 완료/보류 태스크 표시 | 해당 날짜 기준 태스크 처리 현황 | MVP |
| F-11-4 | 일정 이력 표시 | 해당 날짜에 있었던 일정 목록 | MVP |
| F-11-5 | 자유 일기 입력 | 해당 날짜에 대한 자유 서술 메모 추가 | P2 |
| F-11-6 | 이전/다음 날짜 이동 | 하루 단위로 앞뒤 탐색 | MVP |

**비고**: 별도 입력 폼 없음(읽기 전용 취합 뷰). 데이터 원천은 P-01, P-03, P-07, P-04.
